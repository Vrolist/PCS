# 04 — 灾备就绪评分 (DR Score)

> 优先级：P1 | 预估工期：2-3天 | 依赖：VMConfig/HAResource/Snapshot 数据

## 功能描述

为集群和每个 VM/容器打一个灾备就绪评分（0-100 分），综合考量 HA 保护、快照覆盖、备份状态、Agent 启用、网络冗余等因素，直观展示每个资源的"生存能力"。

## 核心价值

- 一眼看出哪些资源"裸奔"（无保护）
- 量化灾备能力，支撑合规审计
- 驱动团队补齐保护措施

## 评分模型

### 单个 VM 评分

| 维度 | 权重 | 得分条件 | 分值 |
|------|------|---------|------|
| HA 保护 | 30% | HA 启用且状态 active | 30 |
| | | HA 启用但状态 inactive | 15 |
| | | 无 HA | 0 |
| 快照保护 | 20% | 快照 ≥1 个 | 20 |
| | | 无快照 | 0 |
| 备份存储 | 20% | 有关联备份存储 | 20 |
| | | 无备份存储 | 0 |
| QEMU Agent | 15% | agent_enabled = true | 15 |
| | | agent_enabled = false | 0 |
| 网络冗余 | 15% | 网卡 ≥2 且有 bond | 15 |
| | | 网卡 ≥2 无 bond | 8 |
| | | 单网卡 | 0 |

### 集群评分

取所有 VM/容器评分的**加权平均**（按资源重要性加权，运行中 > 模板 > 停止）。

### 等级划分

| 分数区间 | 等级 | 颜色 |
|---------|------|------|
| 80-100 | 🟢 优秀 | 绿色 |
| 60-79 | 🟡 良好 | 黄色 |
| 40-59 | 🟠 一般 | 橙色 |
| 0-39 | 🔴 危险 | 红色 |

### 排行榜功能

- 按评分升序/降序排列
- 点击资源名称跳转到详情页
- 筛选：仅显示危险/一般的资源
- 导出评分报告（Markdown/PDF）

## 注意事项

- 评分权重可在 `DetectionRule` 中配置，不同集群可自定义
- 运行中 VM 权重 > 模板 > 停止 VM（停止的不需要 HA）
- 备份状态需要额外数据源（目前 Storage 中有 content_types 字段可判断）
- 分数变化趋势也可追踪（每次扫描记录 DR Score）
